# 🛡️ SENTINEL_AI: Intelligent Fraud Detection System

A comprehensive Full-Stack AI project designed to detect fraudulent transactions using machine learning and an interactive web dashboard.

## 🚀 Features
- Machine Learning Model: Trained Random Forest classifier for precise fraud prediction.
- Interactive Web UI: Built with Streamlit (localhost:8501) for real-time risk assessment and alert generation.
- Data Pipeline: Custom data generation and preprocessing modules.

## 🛠️ Tech Stack
- Python (Pandas, Scikit-Learn, Joblib)
- Streamlit (Frontend Dashboard)
- Git & GitHub (Version Control & Portfolio)
